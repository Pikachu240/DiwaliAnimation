# 🪔 Diwali Reel & Story Animation

આ ફોલ્ડરમાં દિવાળીની સ્ટોરી અને રીલ્સ બનાવવા માટેના પ્રોગ્રામ્સ છે:

### 📁 ફાઇલ્સની વિગત:
1. **`diwali_reel.html`**:
   - લાઈવ ઇન્ટરેક્ટિવ દિવાળી રીલ પ્લેયર.
   - કોઈપણ બ્રાઉઝરમાં ડબલ-ક્લિક કરીને ખોલી શકાય છે.
   - તમારું નામ લખી શકો છો, ફટાકડા ફોડી શકો છો અને **"વિડીયો ડાઉનલોડ (Reel)"** બટનથી સીધો જ વિડીયો ડાઉનલોડ કરી શકો છો.

2. **`make_diwali_video.py`**:
   - પાયથન સ્ક્રિપ્ટ જે 9:16 વર્ટિકલ ફોર્મેટમાં સ્મૂથ એનિમેટેડ GIF/વિડીયો જનરેટ કરે છે.

3. **`run_animation.bat`**:
   - પાયથન સ્ક્રિપ્ટ રન કરવા માટેનો 1-ક્લિક વિન્ડોઝ શોર્ટકટ. ડબલ-ક્લિક કરવાથી `diwali_greeting_reel.gif` બની જશે.
